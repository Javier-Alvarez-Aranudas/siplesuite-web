# Web de SipleSuite

Web estática (HTML, CSS y un poco de JavaScript, sin dependencias) para https://siplesuit.es

- `index.html`: portada
- `siplecost.html`: página de SipleCost
- `legal.html`: aviso legal, privacidad y cookies (versión portafolio, sin venta; al empezar a vender hay que añadir NIF y dirección)
- `img/`: capturas reales de SipleCost sacadas del programa con la obra de ejemplo

Para verla en local: `python -m http.server 8765` dentro de esta carpeta y abrir http://localhost:8765
