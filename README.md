# Web de SipleSuite

Web estática (HTML, CSS y un poco de JavaScript, sin dependencias) para https://siplesuit.es

- `index.html`: portada
- `siplecost.html`, `siplecontrol.html`, `sipletop.html`: una página por programa
- `legal.html`: aviso legal, privacidad y cookies
- `img/`: capturas e ilustraciones de los programas

Para verla en local: `python -m http.server 8765` dentro de esta carpeta y abrir http://localhost:8765
